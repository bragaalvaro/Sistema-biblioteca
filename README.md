## Sobre o projeto

O Sistema de Gerenciamento de Biblioteca foi desenvolvido para facilitar a organização e o controle dos livros, usuários, empréstimos e devoluções de uma biblioteca.

### Objetivo do Projeto

O objetivo do projeto é desenvolver um sistema que facilite o gerenciamento de uma biblioteca, tornando o controle dos livros e empréstimos mais organizado e evitando problemas como perda de informações, dificuldade para localizar livros e falta de controle sobre as devoluções.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API
- Web Audio API
- GitHub
- GitHub Pages

- O diferencial do projeto é reunir em um único sistema as principais funções necessárias para o gerenciamento de uma biblioteca, facilitando o controle das informações e dos empréstimos.

## Instalação e Uso
Para utilizar o sistema, faça o download dos arquivos disponibilizados neste repositório.

Depois, abra os arquivos do projeto em um ambiente de desenvolvimento, como o Visual Studio Code, e execute o sistema conforme as instruções do projeto.


Como utilizar

Acesso ao sistema

Ao iniciar o sistema, o usuário poderá acessar o menu principal e escolher uma das funções disponíveis.

-Ação Função
-Livros Cadastrar, pesquisar e consultar livros
-Usuários Cadastrar e consultar usuários
-Empréstimos Registrar novos empréstimos
-Devoluções Registrar a devolução de livros
-Relatórios Consultar informações sobre livros e empréstimos
-Sair Encerrar o sistema.
